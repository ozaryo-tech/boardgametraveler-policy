# 世界史ノート取り込み（抽出＋録画）→ 解説動画

個人学習用。ページの**文章・画像を抽出**し、**画面も録画**して、PC内で解説動画（mp4）を作ります。Claude API は使いません。

```
[Chrome拡張]  ページを開いて「開始」
   ↓ ダウンロード/WorldHistoryClips/<ページ名>/ に保存
      page.json（見出し・本文・画像の順序つきデータ）
      images/   （ページ内の画像）
      recording.webm（タブの録画。各要素が画面に出た時刻つき）
   ↓
[tools/make_video.py]  → video.mp4
```

## 1. 拡張機能の入れ方
1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
2. 「パッケージ化されていない拡張機能を読み込む」→ `extension` フォルダを選ぶ（更新したときは、同じ画面の「更新」ボタン）。
3. 取り込みたいページを開き、ツールバーの拡張機能アイコンを押す。

## 2. 使い方
| モード | 内容 |
|---|---|
| 抽出＋録画（自動スクロール） | 文章・画像を抽出 → 指定速度で自動スクロールしながら録画 → 最後まで行くと自動で保存 |
| 抽出＋録画（手動） | 自分でスクロールした様子を録画。「停止して保存」で終了 |
| 抽出のみ | 録画なしで文章と画像だけ保存 |

録画中は、そのタブを切り替えたりウィンドウを最小化したりしないでください（映像が止まります）。
画面には、経過時間・ページ数・保存の進み具合が出ます。アイコンのバッジは、録画中が `REC`、保存完了が `OK` です。
録画が途中で止まったり、タブが閉じられたりした場合は、**そこまでの内容を保存**します。

### 次のページも続けて取り込む（連続取り込み）
「次のページも続けて取り込む」にチェックして開始すると、「次へ」のリンクをたどって最大N ページを順に取り込みます。
初回だけ、そのサイトへのアクセス許可を求められます（ページ移動後も操作するため）。
複数ページは**1つのフォルダにまとめて保存**されます（`WorldHistoryClips/<最初のページ名>_<ページ数>p/`）。
録画も1本です。ページの区切りは見出しとして入るので、`make_video.py` はそのまま使えます。

### 対応サイトと、それ以外のサイト
| サイト | 取れるもの | 「次へ」 |
|---|---|---|
| 世界史の窓（y-history.net） | 見出し・本文・画像・キャプション | あり |
| Wikipedia | 見出し・本文・画像（大きい版）・キャプション。脚注や関連項目などの手前で終了。画像には出典ページのURL（`sourcePage`）も記録 | なし |
| YouTube（動画ページ） | タイトル・チャンネル・概要欄・チャプター・字幕。**録画はしません** | なし |
| 上記以外 | `article`・`main` などから本文らしい範囲を自動で判定 | `rel="next"` のリンクがあれば |

YouTubeの字幕は、YouTube側の制限で取得できないことがあります。その場合は、概要欄とチャプターだけを保存します
（`page.json` の `pages[].meta.transcriptStatus` に結果が入ります）。

### 本文範囲を指定する
自動判定がうまくいかないサイトでは、ポップアップの「本文範囲を指定…」を押します。
ページ上で、クリック＝取り込む範囲、Alt+クリック＝除外する要素、↑↓キー＝範囲を広げる・狭める、Esc＝終了。
指定はサイト（ホスト名）ごとに保存され、次回から自動で使われます（ポップアップから消せます）。

### 保存されるもの
- `page.json`：見出し・本文・画像の順序つきデータ。録画した場合は、各要素が画面に出た時刻 `t`（録画開始からのミリ秒）つき。
- `images/`：ページ内の画像。
- `recording.webm`：タブの録画。

## 3. 動画を作る（3段階。途中で確認・修正できます）
必要なもの: Python 3、`pip install pillow`、ffmpeg（PATH が通っていること）

```
python tools/make_video.py plan   "<保存フォルダ>"
   ↓ scenes.json を開いて、文章や使う録画の区間を直す
python tools/make_video.py voice  "<保存フォルダ>"
python tools/make_video.py render "<保存フォルダ>" --scene 2   ← まず1場面だけ試す
python tools/make_video.py render "<保存フォルダ>"              ← 全体
```
保存フォルダ例: `C:\Users\あなた\Downloads\WorldHistoryClips\wh0101-003`

| 段階 | やること | 出力 |
|---|---|---|
| plan | 見出しごとに場面を分け、本文を約90文字ずつのカットに分割。各カットが使う**録画の区間**（その見出しが画面に現れた時刻から次の見出しまで）を割り当てる | `scenes.json` |
| voice | 各カットの文章を音声にする。文章を直して再実行すると、変えたカットだけ作り直す | `_work/audio/` |
| render | 録画の該当区間（映像）＋抽出した文章（字幕・音声）を合成して mp4 にする | `video.mp4` |

### scenes.json の直し方
- `text` : 字幕と読み上げの文章。自由に書き換えてよい（長すぎると字幕が4行で切れます）。
- `source` : `recording`（録画） / `image`（抽出した画像を大きく表示） / `card`（見出しだけ）。
- `start_ms` / `end_ms` : `recording` のとき使う録画の区間（ミリ秒）。映像の速さは音声の長さに合わせて自動で調整（0.4〜1.7倍の範囲）。
- カットの削除・順番の入れ替えも、この JSON を編集するだけでできます。

### 読み上げ（任意・無料）
[VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておくと読み上げます（なければ無音＋字幕）。`--speaker 数字` で話者を変更。

### 要約（任意・無料）
既定は本文をそのまま字幕にします。短くまとめたい場合は [Ollama](https://ollama.com/) のローカルモデルを使い、
`plan` に `--ollama モデル名`（例: `--ollama qwen2.5:7b`）を付けます。

### その他のオプション
- plan: `--max-chars 90`（1カットの文字数）／`--prefer-images`（画像のある場面は録画でなく画像を表示）
- voice: `--no-voice`（無音にする）
- render: `--scene 番号`／`--out 出力名.mp4`／`--font フォントファイル`
- 録画の音声（タブの音）は動画には使いません。ナレーションのみです。

## 4. 注意
- 文章・画像・動画の権利は元のサイトにあります。個人の学習での利用に留め、作った動画は公開しないでください。
  Wikipediaの画像は、`sourcePage` のページでライセンスと表示条件を確認できます。
- 録画は Chrome の `tabCapture` を使います。一部のページ（chrome:// など）では使えません。
- 連続取り込みで移動するのは、同じサイト内のページだけです。
